UI KIT — дизайн-система

Откройте ui-kit.html в браузере. Файл, CSS, JS и папка
assets должны оставаться рядом. Интернет и сборка не нужны.

Вкладка «Поля»: input, selector, multiselector, search, date picker и time picker.
Вкладка «Кнопки»: сохранённая витрина из приложенного HTML.
Вкладка «Компоненты»: десять компонентов с рабочими примерами и состояниями.
Вкладка «Цвета»: вся палитра Colors, цветовые токены компонентов и типовые BG.
Вкладка «Основы»: типографика, отступы, радиусы и тени из Figma.
Вкладка «Таблицы»: обычная таблица с сортировкой и фильтрами столбцов.
Ссылка «Интерфейс»: отдельная страница task-admin.html по приложенному изображению.

  Disabled-иконки сохраняют цвет при наведении.

Поведение:
  Единое скругление полей и кнопок: 4 px.
  Круглые glyph Radio/Toggle и декоративные Badge/Counter сохраняют форму Figma.
  Выпадающие списки, автокомплит и календарь появляются за 140 мс
  после визуальной задержки 20 мс; сдвиг при появлении всего 2 px.
  Вкладки и новое превью появляются плавно, состояния меняются за 120 мс.
  Кнопки в превью и матрице обновляются на месте: при переключении состояний
  не пересоздаются и не повторяют появление из прозрачности.
  Toggle/Checkbox/Radio после ухода курсора показывают обычный цвет своего
  текущего значения (включено, выключено или частичный выбор). Фокус после
  клика не удерживает Hover. Клавиатурный фокус отмечен отдельной обводкой.
  То же правило действует для полей и Textarea: уход курсора после клика
  убирает временную подсветку, сохраняя ввод и выбор; клавиатура возвращает
  подсветку фокуса. Заданные вручную демонстрационные состояния остаются.
  Ввод, выбор и клавиатура работают сразу. При prefers-reduced-motion
  анимации и переходы отключены. Настройки вынесены в --ui-motion-*.
  Автокомплит фильтрует варианты, принимает свободный ввод.
  Стрелки выбирают пункт, Enter подтверждает, Escape закрывает список.
  В простом меню Tab закрывает список; в меню с действиями переводит к ним.
  Календарь: выбор дня, месяца, года; стрелки и PageUp/PageDown работают.
  Отступы календаря: 16 px сверху/снизу, 8 px слева/справа; сохраняются
  при переключении режима и месяцев с разным количеством строк.
  Дата вводится как дд.мм.гггг; диапазон 1900–2099, невозможные даты отклоняются.
  Время: чч:мм, диапазон 00:00–23:59; список с шагом 15 минут.
  Произвольное корректное время можно ввести вручную.
  Плавающая метка, required, hint, clear, leading/trailing icons, suffix,
  ошибки и нативный disabled доступны в одной основе Field.

Файлы для повторного использования:
  design-tokens.css + form-controls.css + form-controls.js + assets/
  showcase.js содержит только демонстрационные данные и витрину.
  buttons-showcase.js — интерактивное превью и матрица кнопок.

Подключение:
  <link rel="stylesheet" href="design-tokens.css">
  <link rel="stylesheet" href="form-controls.css">
  <div id="city"></div>
  <script src="form-controls.js"></script>
  <script>
    const field = new UIKitControls.Field(document.querySelector('#city'), {
      type: 'input', size: 'l', label: 'Город', required: true,
      hint: 'Выберите или введите свой', autocomplete: true,
      options: ['Москва', 'Казань', 'Санкт-Петербург']
    });
    field.root.addEventListener('ui:change', event => {
      console.log(event.detail.value);
    });
  </script>

API:
  type: input | selector | multiselector | search | date | time
  size: l | m | s
  options: строки или {value, label, description}
  setValue(value), validate(), open(), close(), destroy()
  события: ui:input, ui:change, ui:search; detail: {value, type}
  Для рабочего экземпляра оставьте state: 'default'; state служит
  для демонстрации заранее заданных состояний.

Форма встречи демонстрационная: подтверждение показывает выбранные значения
локально и не отправляет их на сервер. Поиск использует локальные примеры.

Проверено в Chrome: ввод и очистка, стрелки/Enter/Escape/Tab, фильтрация и
пустой результат, невозможные даты и високосный год, переключение месяца/года,
границы времени, disabled, валидация формы, размеры 300×40/32/24,
геометрия оригинальных SVG, мобильная раскладка на 320 и 390 px.

МУЛЬТИСЕЛЕКТОР И UNIT MENU

Добавлено по вариантам Figma:
  https://www.figma.com/design/pUX3P9VmLBkdQ1vIupjeSr/?node-id=11227-12561
  https://www.figma.com/design/pUX3P9VmLBkdQ1vIupjeSr/?node-id=13843-26731
  .unitMenu: 11194:90573; .collapse: 11220:10766; .menuButton: 11271:4509.

В витрине: три рабочих селектора и три самостоятельных меню со строками.
Multiselector также доступен в живом превью и матрице L / M / S.

Настройки Field:
  type: 'multiselector' (или type: 'selector', multiple: true)
  value: массив строковых значений; setValue([...]) заменяет выбор.
  commit: 'immediate' (по умолчанию) или 'save'.
  bulkActions: true (по умолчанию у мультиселектора) или false.

В режиме immediate каждое действие обновляет value и отправляет ui:change;
меню остаётся открытым. В режиме save выбор хранится в draftValue до нажатия
«Сохранить». Клик вне меню, Escape, закрытие триггером или уход фокуса отменяют
черновик. Обычная кнопка очистки поля сразу очищает подтверждённое значение.
«Сбросить все» внутри меню с сохранением изменяет только черновик.

Новые события:
  ui:draft — предварительный выбор; detail.value содержит массив черновика.
  ui:cancel — черновик отменён; detail.value содержит сохранённый массив.
  ui:change — подтверждённое значение; detail.value для multiple — массив.
  onChange получает только подтверждённый выбор.

Формы: для каждого подтверждённого значения создаётся hidden input с name.
Получить все значения: new FormData(form).getAll('industries').
Черновик в FormData не попадает. Disabled-поля не участвуют в отправке.

Строка options:
  строка либо {value, label, description?, icon?, disabled?}.
  icon: путь к оригинальному SVG, например 'assets/icons/b0b35.svg'.
  Для цветовых состояний используйте объект:
    {default:'assets/icons/b0b35.svg', selected:'assets/icons/045bb.svg',
     hover:'assets/icons/6386a.svg'}.
  Иконки отображаются в собственных размерах, без перерисовки или растяжения.
  Короткая строка: 34 px; с описанием: 54 px. Иконка и галочка: 18×18.

Группа options:
  {label, children:[...options], expanded?:true, disabled?:true}.
  Группа раскрывается по клику, Enter/Space или стрелке вправо; стрелка влево
  сворачивает группу или переводит фокус к родителю. Поддержана вложенность.
  Группа не является значением; выбрать можно конечные строки.
  «Выбрать все» выбирает все доступные конечные строки, в том числе скрытые
  в закрытых группах. Заблокированные строки/группы пропускаются.
  «Сбросить все» убирает весь выбор. Наборы значений не содержат дубликатов.

Пример:
  const field = new UIKitControls.Field(document.querySelector('#industries'), {
    type:'multiselector', name:'industries', label:'Отрасли', size:'l',
    value:['cyber'], commit:'save', bulkActions:true,
    options:[
      {label:'Информационные технологии', expanded:true, children:[
        {value:'cyber', label:'Кибербезопасность',
         description:'Защита данных', icon:'assets/icons/b0b35.svg'},
        {value:'cloud', label:'Облачные сервисы'}
      ]},
      {label:'Агропромышленность', children:['Сельское хозяйство']}
    ]
  });

Самостоятельное меню без поля:
  const menu = new UIKitControls.Menu(document.querySelector('#menu'), {
    label:'Направления', options:[...], value:['cyber']
  });
  Menu использует тот же renderer и API выбора. По умолчанию множественный
  выбор без массовых действий; можно включить bulkActions и commit:'save'.
  Встроенное меню остаётся открытым; destroy() удаляет экземпляр.

Tab из открытого поля переводит фокус к массовым действиям и кнопке сохранения;
Shift+Tab из первого действия возвращает к полю. Enter/Space выбирает или
снимает выбор; Escape отменяет черновик. Длинный выбор показан текстом с
затуханием и счётчиком «еще N»; полный список доступен в значении и title поля.

Дополнительно проверено в Chrome: множественный выбор, выбор/сброс всех,
сохранение и отмена черновика, порядок Tab, раскрытие вложенных групп,
массовый выбор скрытых пунктов, disabled, сериализация FormData, точные размеры
строк/иконок, состояния Colors, размеры L/M/S и мобильный экран 320/390 px.

ДАТА И ДИАПАЗОН A → B

Figma:
  https://www.figma.com/design/pUX3P9VmLBkdQ1vIupjeSr/?node-id=13843-24533

Настройки Date picker:
  type:'date', selectionMode:'single' (по умолчанию) или 'range'.
  monthsToShow: 2 (по умолчанию в range) или 1.
  При ширине экрана меньше 560 px диапазон автоматически показывает одну сетку.
  closeOnSelect: true — закрыть после выбора B; по умолчанию range остаётся
  открытым для просмотра подсветки. Одиночная дата закрывается после выбора.

В диапазоне первый клик задаёт A, второй — B. До выбора B наведение мыши
или перемещение стрелками показывает предварительную подсветку. Границы
выделены accent/main, промежуточные даты — calendarpanel/date/bg/ranger.
После завершения диапазона новый клик начинает новый выбор. Можно выбрать
даты в обратном порядке — A станет более ранней датой, B более поздней.
Один день может быть обеими границами. Крестик очищает A, B и подсветку.

Сетка поддерживает переход между месяцами/годами и клавиатуру. На узком
экране конец диапазона в следующем месяце можно выбрать после стрелки «Вперёд».
Витрина содержит примеры одиночной даты и диапазона, а также переключатели
режима в живом превью и матрице L/M/S. «Два месяца рядом» отключается отдельно.
Отступы каждой сетки: 16 px сверху/снизу, 8 px слева/справа.

Значение:
  value: '13.06.2024 – 13.07.2024' либо
    {start:'13.06.2024', end:'13.07.2024'} при создании или setValue.
  field.value — строка; field.range — {start, end} со строками дат.
  После выбора только A: value содержит дату A, range.end пустая строка.
  validate() требует обе границы и проверяет календарные даты 1900–2099.
  Можно ввести диапазон вручную через тире или дефис; после проверки он
  нормализуется к «дд.мм.гггг – дд.мм.гггг» в хронологическом порядке.
  Нативная FormData содержит строку value под указанным name.

События range:
  ui:input — ввод или предварительный выбор A.
  ui:change — выбор B, очистка или программный setValue.
  detail: {value, type:'date', range:{start, end}}.
  Наведение показывает только подсветку и не меняет выбранное значение.

Пример:
  const period = new UIKitControls.Field(document.querySelector('#period'), {
    type:'date', selectionMode:'range', name:'period', label:'Диапазон дат',
    required:true, size:'l', monthsToShow:2,
    hint:'Выберите начало A, затем конец B',
    value:{start:'13.06.2024', end:'13.07.2024'}
  });
  period.root.addEventListener('ui:change', event => {
    console.log(event.detail.range.start, event.detail.range.end);
  });
  // Сброс через API, аналогично крестику:
  period.setValue('');

Helpers:
  parseDateRange(value) — {start:Date|null, end:Date|null} или null при ошибке.
  formatDateRange({start:Date, end:Date}) — строка диапазона.

Проверено в Chrome: границы A/B и цвета из Colors, предварительная подсветка,
выбор в обратном порядке и одного дня, переход через месяц и високосный день,
сохранение начатого выбора при закрытии, сброс крестиком, ручной ввод и ошибки,
клавиатура, выбор месяца/года, границы 1900–2099, одна/две сетки, переключение
при изменении ширины экрана, 320/390 px, отступы 16/8 px и размеры L/M/S.

COLORS И BG

Figma:
  Colors: https://www.figma.com/design/pUX3P9VmLBkdQ1vIupjeSr/?node-id=2784-2
  BG: https://www.figma.com/design/pUX3P9VmLBkdQ1vIupjeSr/?node-id=4446-2

Полный экспорт: 78 цветов Color, core и 661 переменная Color, token.
Палитра содержит dark, accent, success, caution, critical, adv1 и adv2,
включая прозрачные цвета. Токены компонентов сохраняют исходные имена
и связи на базовую палитру; CSS-переменные используют прежний префикс --ds-.
Все 109 ранее подключённых цветов сохранили значения.

BG:
  White — dark/W, #FFFFFF, --ds-dark-w.
  Grey — dark/50, #FAFAFA, --ds-dark-50.
  Border — dark/300_opacity, rgba(54,57,62,0.13), --ds-dark-300-opacity.
  Border не содержит заливки. Образцы BG имеют размер 300×300 и радиус 4 px
  на большом экране; на узком экране уменьшаются до ширины контейнера.

В витрине: поиск по имени, HEX, CSS-переменной или связанному токену;
переключатели «Палитра / Токены / Все» и фильтр групп. Фон палитры можно
переключить между белым и серым. Нажатие на образец копирует цвет;
название токена, HEX и CSS-переменная копируются отдельными кнопками.
У прозрачных образцов показывается процент; по нажатию копируется rgba.
Копирование работает и при открытии файла локально, без сервера.

Оригинальные круги палитры из Figma сохранены в assets/colors без изменения
геометрии. В Color, core у adv1/700 значение #6C59E5, а отвязанный образец
на странице Colors имеет #6C5AE5. В карточке видны оба значения; токен
сохранён как в коллекции переменных. Связанные цвета компонентов используют
точное значение токена.

Work In Progress: отдельно показаны 20 образцов dark2 и dark updated.
Для них не создавались вымышленные токены; они помечены как образцы без
отдельных переменных и не подменяют основную палитру компонентов.

Экспорт:
  design-tokens.css — все 739 CSS-переменных; связи сохранены через var(...).
  design-tokens.json — значения RGBA, HEX, исходные имена, id, коллекции,
    alias, CSS-переменные, прозрачность и данные BG.
  design-tokens.js — те же данные для автономной витрины без fetch.
  colors.css + colors.js — только интерфейс вкладки «Цвета».
Для компонентов в соседнем продукте по-прежнему достаточно подключить
design-tokens.css, form-controls.css, form-controls.js и assets.

API: window.UIKitComponents.
  TextArea(mount, {label, name, value, required, maxLength, hint, disabled})
    value, setValue(value), validate(); события ui:input и ui:change.
  Toggle / Checkbox / Radio(mount, {label, name, value, checked, disabled})
    checked, setChecked(bool, {emit}); событие ui:change.
    Checkbox: indeterminate:true и setIndeterminate(bool) для частичного выбора.
    Toggle: position:'left' | 'right'; Radio объединяются одинаковым name.
  Counter(mount, {value, tone, size:18|24}) — setValue(value).
  Badge(mount, {text, tone, counter, leading, trailing}) — пассивная метка.
  Status(mount, {text, tone, style:'round'|'text', size:18|24, disabled})
    tone: success | critical | progress | caution | neutral | purple | blue.
  Tabs / SegmentControl(mount, {items, value, label})
    items: [{value, label, counter, leading, trailing, disabled, content}].
    value, setValue(value, {emit}); событие ui:change.
  CollapseString / CollapseSection(mount, {title, size:'h2'|'body', open,
    content, nearAction, actions, leading, trailing, state})
    setOpen(bool, {emit}); ui:change с detail.open; ui:action с detail.label.
    Collapse остаётся совместимым именем для CollapseSection.
    state: default | hover | active; у Section также active-hover.
    Нажатие на заголовок раскрывает блок. Кнопки действий работают отдельно.
  CollapseButton(mount, {label, color:'neutral'|'accent', open, content})
    setOpen(bool); ui:change с detail.open.
  Tooltip(button, {text, placement, delay:90}) — show(), close(), destroy().
    placement: top, top-left, top-right, left, right, bottom, bottom-left,
    bottom-right. Края экрана учитываются автоматически.
  У всех экземпляров доступны root и destroy(). Строковый content выводится
  как текст; для сложного содержимого передайте DOM Node.
  state используется для показа состояния в витрине; для рабочего экземпляра
  оставьте default. Не подключайте components-showcase.js в свой продукт.

Пример:
  const comment = new UIKitComponents.TextArea(document.querySelector('#comment'), {
    label:'Комментарий', name:'comment', maxLength:64, required:true
  });
  const choice = new UIKitComponents.Checkbox(document.querySelector('#accept'), {
    label:'Подтверждаю', name:'accept', value:'yes', checked:false
  });
  choice.root.addEventListener('ui:change', event => {
    console.log(event.detail.checked);
  });

Повторное использование таблицы:
  Подключите foundation-tokens.css, tables.css и tables.js, а также
  существующие стили и реализацию UIKitControls.Field и UIKitComponents.
  new UIKitTables.DataTable(mount, {label, rows, columns}).
  columns: [{key, label, width, filter, options, format, compare}].
  Необязательный compare(leftValue, rightValue, leftRow, rightRow) задаёт
  порядок значений столбца; направление и стабильность сохраняет таблица.
  filter: text | select | date | number. options — значения для select.
  Дата: дд.мм.гггг. Числовой диапазон: {min, max}.
  setSort(key, 'ascending' | 'descending' | null), setFilter(key, value),
  setRows(rows), reset(), destroy(); root и visibleRows доступны экземпляру.
  Событие ui:table-change содержит count, total, sort и filters.
  tables-showcase.js содержит только демонстрационные данные витрины.

Инспектор интерфейса

  «Шрифты: выбрать текст» включает выбор текста мышью или клавиатурой.

  от фактической привязки к токену. Токен можно скопировать кнопкой.

  Локальные размеры без совпадения отмечены «без токена»; на узких участках
  и мобильных экранах показано только число для читаемости.
  Подсветка не меняет размеры и положение элементов. Измерения обновляются

  Для обычных действий выключите режимы выбора; подсветку отступов можно
  оставить включённой. Escape выключает выбор шрифтов, компонентов и цветов;
  «Всё выключить» сбрасывает все четыре режима. Инспектор работает в формах.

Компоненты и цвета в инспекторе
  «Компоненты: показать состав» подсвечивает все видимые компоненты.
  Клик фиксирует контрол: показаны название, источник, вариант, размеры,
  скругление, состав, родительские компоненты и количество экземпляров.
  Фиолетовые границы — все компоненты; бирюзовые — выбранный и его части;
  пунктир — остальные экземпляры того же типа. В составе можно выбирать
  вложенные компоненты; в общем списке — группу компонентов.
  Компоненты UI KIT, их части и композиции экрана различаются по источнику.
  Скрытые части не подсвечиваются.
  «Цвета: выбрать участок» показывает фон, текст, рамки и цвета SVG.
  Если элемент прозрачный, показан ближайший видимый фон под ним.
  Для каждого цвета доступны фактический HEX, прозрачность, точный токен
  палитры (например dark/100), применённый токен компонента и источник.
  Совпадение по значению отличается от привязки к токену. Цвет без точного
  совпадения не получает вымышленного имени: показаны HEX и соответствующая
  отметка. HEX и названия токенов можно копировать.
  Учитываются hover, локальные настройки, цвета SVG и фильтры иконок.
  Режимы работают вместе со шрифтами и отступами, внутри форм и на узких
  экранах. В режиме выбора клик исследует контрол, не выполняя его действие.
  Дополнительные файлы: task-inspector-extras.js, design-tokens.js.
  Проверены состав и повторные экземпляры, точные базовые и семантические
  токены, неизвестные цвета, SVG, сочетание режимов, формы, Escape,
  экраны 1318/390/320 px и обычные действия после выключения инспекции.
