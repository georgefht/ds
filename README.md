# UI KIT · компоненты и интерфейсы

Последняя итерация дизайн-системы и двух интерактивных интерфейсов на её основе.

## Открыть

Скачайте репозиторий целиком или клонируйте его. Откройте `ui-kit.html` в браузере; сборка и интернет не нужны. CSS, JS и каталог `assets` должны оставаться рядом с HTML.

| Страница | Содержимое |
| --- | --- |
| [ui-kit.html](ui-kit.html) | Поля, кнопки, компоненты, палитра, типографика, отступы, радиусы, тени и таблицы |
| [task-admin.html](task-admin.html) | Админка проверок контрагентов: конфигурации, запуск, журнал, сортировка и фильтры |
| [interface-2m.html](interface-2m.html) | SaaS Ops Desk: очередь заявок, карточка, формы, массовые действия, настройки и экспорт CSV |

В интерфейсах доступен инспектор шрифтов, отступов, компонентов и цветовых токенов. В режиме инспекции клик исследует компонент; выключите режим для обычных действий.

## Последние исправления

- Вкладки 2M: высота 40 px, типографика 14/18, адаптивная ширина и выровненные счётчики.
- Кнопка «Запустить»: состояние «Только loader» из ДС, стабильная ширина, защита от повторного запуска и возврат в обычное состояние.

## Основа

Inter, переменные Colors и основы экспортированы из [Figma UI KIT](https://www.figma.com/design/pUX3P9VmLBkdQ1vIupjeSr/). Токены находятся в `design-tokens.*` и `foundation-tokens.*`, SVG и шрифт — в `assets`. Лицензия шрифта сохранена в `assets/fonts`.

Подробное описание компонентов и поведения: [README.txt](README.txt).

## Ограничения демонстрации

Все данные интерфейсов демонстрационные. Сервер и внешние службы не подключены. 2M хранит изменения в localStorage текущего браузера. Для работы с реальными данными потребуется подключение API.
